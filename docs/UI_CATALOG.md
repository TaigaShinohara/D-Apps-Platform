# D-Apps 詳細ページのUI

| パーツ          | 役割・状態                                                     | 狙い                                                                                                            |
| --------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| AppHero         | 日英のアプリ詳細の冒頭。プレビュー画像、ロゴ、説明のみの各状態 | 既存の見出しだけでは伝わりにくい作品の個性を、素材1点と短い文で伝える。配布情報と画像の枠を分けて読み順を保つ。 |
| AppIcon         | 配布中のアプリ一覧のアイコン。実物か頭文字                     | 一覧からアプリを見つけるための目印。                                                                            |
| ShowcaseSection | 開発中・過去の作品とスキルの一覧                               | 作品は詳細ページ、スキルは公開リポジトリへ進める。                                                              |
| DownloadLink    | 公式ストア・Web・公開プレビュー・承認済み直接配布へのリンク    | 利用者が移動先を判断できる既存ラベルを使う。                                                                    |

詳細ページの背景色とアクセントは作品ごと、見出し・本文の階層と余白はD-Appsで共通。素材の出どころは [THIRD-PARTY.md](../THIRD-PARTY.md) に記録する。
