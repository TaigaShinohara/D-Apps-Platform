## 見積りの前提（2026-11-17）

配信は Google Firebase Hosting に変更しました。[公式料金](https://firebase.google.com/docs/hosting/usage-quotas-pricing)では、保存 10 GB と転送 10 GB/月が無料枠です。Blaze の超過分は保存 US$0.026/GB、転送 US$0.15/GB です。無料枠を使う Spark には利用制限があります。Blaze に請求上限はなく、予算通知も強制停止ではありません。

| 想定                                                               | Hosting の概算（税・為替・他サービスを除く）      |
| ------------------------------------------------------------------ | ------------------------------------------------- |
| OneClip 月 1,000 DL：約 3.82 GB ＋ ページ転送 1 GB、保存 1 GB 未満 | 無料枠内なら US$0                                 |
| 月 100 GB 転送、保存 10 GB 以下                                    | 超過 90 GB × US$0.15 = US$13.50                   |
| 上記に有効な US$10 クレジット全額を充当できた場合                  | US$3.50。実際の請求先・残高・対象条件の確認が必要 |

[Google AI Pro の公式開発者特典](https://developers.google.com/profile/help/benefits)には月額 US$10 の Cloud クレジットがあります。有料プラン本人の Developer Profile 連携と、適用する Cloud Billing アカウントの確認が必要です。本人の承認後、対象請求先への適用と今後の自動適用、専用プロジェクトの Blaze 接続を確認しました。残高・期限・共用請求先の識別情報は非公開記録に保存します。他プロジェクトの今後の消費や公開後の実請求は継続確認が必要です。Google 側の追加支出を発生させて特典を消費する必要はありません。無料枠内で始め、必要な利用分へ充当します。

Route 53 の既存 hosted zone/DNS 料金は Google クレジットの対象外です。ドメイン更新料、既存の別サービス、古い Hosting 版の保存量、超過転送量、税・為替を区別します。Google 側の月額目標は従来どおり 1,000 円以内ですが、上限を保証しません。使用量とクレジット残高を確認し、対象外なら自動で有料設定に切り替えません。

## 変更した要件

- 運営者による個人情報の入力受付・追跡・訪問者ログ保存は行いません。
- ユーザーの選択により、Google が IP アドレスを数か月保持する Firebase Hosting を採用し、日英の方針に明記しました。
- 非公開 S3/OAC、CloudFront Free、WAF、CloudFormation は廃止。Google 管理の Hosting/CDN/TLS、Terraform と短命 WIF 認証へ変更。
- 配信停止はリンクとバイナリを除いた新しい版を公開し 404 を確認します。410 の応答やダウンロード済みファイルの回収は保証しません。
- Firebase Hosting に GET/HEAD だけを許可するサイト設定はありません。フォーム/API は設けず、実環境でのメソッドごとの応答は更新時に確認します。
- デフォルトの web.app/firebaseapp.com でも公開されます。カスタムドメイン切替前の release も公開承認が必要です。
