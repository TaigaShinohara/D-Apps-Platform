## OneClip

Start with [OneClip’s instructions and known limitations](/en/apps/oneclip/). App issues can be checked or reported through [OneClip’s GitHub Issues](https://github.com/TaigaShinohara/OneClip/issues).

## This website

Report broken links or display issues through [D-Apps GitHub Issues](https://github.com/TaigaShinohara/D-Apps-Platform/issues). This website has no form that receives your information.

GitHub is an external service and may require an account to post. Do not include names, email addresses, passwords, API keys, personal logs, or sensitive screenshots in public issues.

## Security issues

Do not post vulnerability details or exposed secrets in a public issue. Follow the [security reporting instructions](https://github.com/TaigaShinohara/D-Apps-Platform/blob/main/SECURITY.md). Security issues in a downloaded app belong with that app’s publisher.
