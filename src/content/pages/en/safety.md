## Official release files

Direct downloads are checked against the developer’s official release. We publish the version, size, SHA-256, supported platforms, signing and notarization information, and original release page. We do not repackage apps or bundle other software.

Store links lead to official product pages. We do not use shortened URLs, advertising detours, or automatic downloads.

## Be precise about verification

A hash checks whether files match; it is not evidence that software is harmless. Signing and notarization do not eliminate every defect or risk either. Each app lists its tested scope and known limitations.

We do not ask you to disable system-wide security protections. If installation shows an unexpected warning or signature mismatch, stop and check the original release information.

## If a problem is found

We publish a version of the site without the affected links and files, then verify the delivery cache update and that those URLs no longer serve the files. We cannot recall copies already saved on a device. A fixed release receives a new versioned URL and release notes. See [support](/en/support/) for reporting information.

## Protecting the website

We use HTTPS, a Content Security Policy, and dependency checks. D-Apps operates using aggregate metrics and pre-publication testing. See our [privacy policy](/en/privacy/) for Google’s use and retention of visitors’ IP addresses as the delivery provider.
